# Source provenance

This package implements a small private packed word mechanism under the repository MIT license. Selected byte addresses derive from the retained source, signature decoder and sponge consumers. Their original source identities remain recorded and their implementation is unchanged. The addresses are a subset of those consumers, not a complete signature relation.

Pinned Plonky3 version 0.8.0 supplies field arithmetic, AIR builders, the actual symbolic collector and the actual native constraint checker. The dependency source and its upstream licenses remain in the original packages. No proving backend is copied or executed by this experiment.

Independent Python integer packing and direct source slices produce the synthetic expected vectors without calling Rust. Native controls use the actual AIR equations rather than an external acceptance callback. All fixture inputs are public deterministic research data. No wallet or private user data is included.
