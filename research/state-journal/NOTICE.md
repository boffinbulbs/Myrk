# Source and attribution

The journal, worker, tests and frame literals are original Kova MIT source. The external Windows guard is preserved byte-for-byte from `research/trace-domain/run_guarded_windows.ps1`, itself retained through the earlier Kova diagnostics. The repository MIT license is copied unchanged.

The implementation uses Rust standard library file and process APIs. No Rust or Microsoft implementation source is copied into the crate. The source review uses installed Rust 1.94.1 documentation, with its original MIT OR Apache-2.0 attribution, and the primary platform references linked in the README. Exact source identities, the dependency boundary and measured records appear in provenance.json and validation.json.
