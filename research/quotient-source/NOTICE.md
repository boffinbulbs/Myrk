The quotient evaluator derives from the PlainEval and quotient_values_inner bodies in p3-uni-stark 0.8.0. The original authorship and dual MIT and Apache 2.0 notices are retained in LICENSE-MIT and LICENSE-APACHE. The extraction diff records those two source blocks. The actual ProverConstraintFolder, constraint layout, alpha decomposition and field operations remain upstream implementations.

The context, composite owner and main commitment adapter derive from research/source-stark. That laboratory remains unchanged. The fresh package removes its complete prover entry and adds one canonical quotient evaluation file. New storage and diagnostic adaptation code uses the repository MIT license in LICENSE. The source differences and byte identities are recorded separately from execution results.

Backend modules and the original main preparation and extension sources are compiled by path without changing their bytes. Diagnostic setup derives from source-stark/tests/common.rs and delegates the retained hiding Merkle commitment, SHA3 framing, seeded synthetic randomness and optimized DFT methods. It records effect counts rather than leaf digests or entropy bytes. The fixed trace is a retained public synthetic fixture.

The independent integer reference implements the published field and quotient formulas separately. It shares captured main evaluations and the actual transcript challenge with the candidate. This establishes conditional arithmetic comparison, without independently reconstructing the LDE or authenticating a commitment root.

Construction stops before quotient masking, quotient commitment, auxiliary commitment and opening. No complete proof, payment authorization, ledger acceptance or system security result is inferred from this package. The full private signature relation remains outside its small storage class.
