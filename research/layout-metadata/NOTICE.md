# Source and scope

This is an original Kova diagnostic adapter for the pinned Plonky3 0.8.0 AIR interfaces. Its constant aware degree rules follow `p3-air` symbolic expressions. Those interfaces, cached two adic degree semantics, selector rules and constant simplifications remain attributable to the Plonky3 authors. Registry licenses and checksums remain in the resolved graph and lockfile.

The actual complete relation is imported unchanged from [signature-overlay](../signature-overlay/README.md). Its original source derivation, MIT license, imported modules and third party notices remain applicable. This adapter neither copies nor executes that laboratory's old symbolic diagnostic or native constructor. Borrowed row windows and scalar metadata replace expression graph retention for this separate diagnostic only.

The operation counter describes attached metadata algebra charges. Detached literal work is deferred until attachment and can be charged again when a copied detached expression is reused. Discarded detached expressions and field arithmetic outside the metadata type are not counted. This counter is not a count of every process operation. External resource limits remain required.

No proof backend, witness verifier, cryptographic profile or payment acceptance rule is supplied by this component. Original project source remains under the repository MIT license, copied here unchanged.
