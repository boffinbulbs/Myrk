# Source provenance

The component imports the exact original integer multiplication and UseHint constraints from signature-complete-native and the exact clock from signature-storage. Those source snapshots and their MIT attribution remain unchanged. New mode, source binding, consumer and diagnostic code uses the copied project MIT license.

The mode schedule follows the packed relation's forward butterfly, inverse butterfly, normalization and output intervals. This component retains eight synthetic held operand tuples and sixteen synthetic terminal outputs. It does not import the complete signature constructor or replace the private payment statement.

Multiplication bit vectors and expected outputs are selected unchanged from the independent arithmetic reference record. Hint witnesses encode existing boundary reference fields into the original bit layout. Expected decomposition and output values are not recomputed. The selected cases cover positive and negative low parts, edge, borrow and overflow encodings.

This is a component constraint experiment. Source ownership in the full signature, transaction binding, private ledger joins, complete proof generation and security composition remain separate work. The inherited clock unit tests and earlier reference producers are not selected.
