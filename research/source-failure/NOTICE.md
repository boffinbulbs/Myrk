# Source provenance

This laboratory derives from source-prover and retains its original backend, fixed relation, serial quotient kernel, normalized coupled masks, auxiliary sampler and transcript. The original MIT and Apache 2.0 notices remain in LICENSE-MIT and LICENSE-APACHE. New owner and diagnostic adaptation code uses the repository MIT license in LICENSE. Earlier source snapshots and their measurements remain unchanged.

The normal public prove entry selects no diagnostic fault. The private diagnostic selector has two fixed filesystem actions and cannot supply a path, witness, root, challenge or acceptance result. The actual committed main lease is retained for failure closure checks. The same owner seals the real quotient source before truncation, and the real auxiliary write encounters the diagnostic sentinel through its original exclusive creation path.

The new owner releases its active writer claim when Pending.abort has closed the descriptor and recorded failure. This includes an orphan cleanup branch. The failed phase, first cause and existing unlink authority remain unchanged. Original private opening flag logic and transcript error handling are retained.

The observer and deterministic input fixtures derive from source-prover. It delegates the actual original MMCS, transforms, hashing and RNG. Fingerprints describe delivered bytes from directly observed streams. Seeded forks have separate journals, so these observations are not a complete entropy transcript.

The selected cases exercise real source access errors and a caught infallible storage unwind. They do not construct an accepted proof, call a verifier, test an opening or establish a hiding or quantum security theorem. The sentinel collision is an isolated diagnostic fixture. Cleanup checks its fixed path, file kind, bounded body and length before removal. It does not establish protection against an adversary replacing filesystem paths concurrently.
