# Source provenance

The new scalar inventory follows inspected preparation, ownership, commitment, opening and folding source. It imports no previous model or cryptographic implementation. Project code retains the copied MIT license. Existing backend, dependency and reference licenses and notices remain with their source packages.

[Source evidence](source-evidence.json) records the exact inspected registry implementations for Plonky3 0.8.0. [Inventory identities](inventory.json) bind the retained project source and saved experimental records. Registry source was inspected without execution. The runtime freeze also covered those local registry files. Reconstructing that freeze requires the exact dependencies recorded in the preceding laboratories.

The copied Windows guard is unchanged. Runtime identities cover the selected interpreter and its four root runtime libraries. They do not constitute a complete operating system or interpreter supply chain audit. Text identities normalize CRLF to LF. No binary fixtures are read by this inventory.
