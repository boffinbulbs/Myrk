# Source provenance

The inventory reads the existing packed relation and its actual imported source paths without changing or executing those implementations. Original licenses and attribution remain with those packages. New inventory code and documentation use the copied project MIT license.

Physical constant parsing is independent of Rust AIR evaluation. Family descriptions and conservative consumer intervals are source reviewed annotations. They are not an automatic formal dataflow analysis or a new cryptographic result. Earlier output lifetime AIR experiments retain their separate recorded scope and were not replayed.

The copied Windows guard is unchanged. Local execution identities include the selected Python executable and root runtime libraries. They do not constitute a complete operating system or standard library audit. The hypothetical arithmetic overlay is not implemented by this inventory.
